Edy P2P Chat - Fresh Android Project

1) Create a NEW empty GitHub repository.
2) Extract this ZIP and upload ALL files/folders to the repository.
3) Commit to main.
4) Open Actions -> Build Edy P2P Chat APK -> Run workflow.
5) When it finishes, open Artifacts and download Edy-P2P-Chat-APK.

The Android app connects to a TCP server on port 5000.
Run server.py on the PC that should act as the server.

IMPORTANT: server.py is for the PC/server side and is not packaged into the APK.
